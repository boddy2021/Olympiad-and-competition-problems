# Olympiad and Competition Problems

This repository contains solutions to various problems from olympiads and competitions, solved in C and C++. I participated in these olympiads and competitions in highschool.

### Features:
- **Problem-solving**: Challenges from multiple programming contests and olympiads.
- **Languages**: Solutions provided in both C and C++.
- **Algorithmic approach**: Focus on algorithms, data structures, optimizations, and problem-solving strategies.

### I used:
- C
- C++
